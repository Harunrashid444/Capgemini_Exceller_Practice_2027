# Capgemini Exceller Practice 2027

A single-page study module for the Capgemini Exceller online assessment, stages 2–5:

- **Technical Module**: AI Literacy, Situational Judgement and Problem Solving notes with practice MCQs
- **Debugging Assessment**: a debugging method, C/C++/Java trap lists and 31 buggy programs with fixes
- **AI-assisted Coding**: workflow, prompt template and 15 practice tasks with reference solutions
- **Cognitive Assessment**: Motion/Grid/Switch challenge strategies and a grid memory drill
- Interview quick prep and a last-look cheat sheet

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
Progress is saved in your browser's local storage.

Formats are compiled from public prep sites and candidate reports; Capgemini has not published an official syllabus. Check your invitation for the exact pattern.
